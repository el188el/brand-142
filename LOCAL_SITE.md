# Запуск сайта на оборудовании без интернета

1. Скопируйте или распакуйте **весь сайт целиком** на оборудование.
2. Откройте корневой `index.html` в браузере.
3. Нажмите «Открыть виртуальный тур». Самостоятельный вход в тур —
   файл `tour/index.html`.

Не переносите HTML-файлы отдельно от папок `tour`, `css`, `js`, `fonts`,
`img` и `assets`. Папка `tour/tiles` содержит все панорамы.

Для такого запуска не нужны интернет, сохранение в браузере, Python или
локальный сервер. Конфигурация тура загружается обычным JS-файлом, а при
открытии через `file://` плеер использует встроенный CSS 3D вместо WebGL.
При размещении на обычном локальном или публичном веб-сервере остаётся WebGL.

## При изменении конфигурации тура

После правок `tour/pano.xml` разработчику нужно выполнить:

```sh
python3 scripts/build_tour_config.py
```

Файл `tour/pano-config.js` хранится в репозитории и уже готов к локальному
запуску. На самом оборудовании ничего собирать или устанавливать не нужно.
